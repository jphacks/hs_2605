
# [12:05:11] - MAGUS Council → codex, claude

Please create a Python class named `Brain` and a main execution script based on the following specifications.

### [Project Goal]
The system receives raw data from a distance sensor (mmWave radar), removes noise, identifies the chest position, counts the respiration rate, determines the status (OK/STILL/EMPTY/CHECK/ALERT),

### [Input Data Format (from the board via stdin)]
- One text message per line (comma-separated, no spaces, ending with `\n`).
- Configuration line: `C,first_cm,step_mm,num_bins,scale`
- Data line (20 frames per second): `D,seq,t_ms,I0,Q0,I1,Q1,...,In-1,Qn-1`
*Note: The D-line contains raw I and Q signal pairs for each distance bin.

### [Brain Class Logic Requirements]
1. **Find Chest**: For each distance bin, calculate the displacement (phase) using `np.arctan2(Q, I)` and `np.unwrap`. Track the variance over the last 2 seconds and lock onto the bin with the highest variance as the chest position (`chest_cm`).
2. **Noise Removal**: Apply a 4th-order Butterworth bandpass filter (`scipy.signal.butter`) between 0.15 Hz and 0.6 Hz (corresponding to 9–36 breaths per minute) to the locked chest displacement data to extract the respiratory wave (`disp_mm`).
3. **Count Breaths**: Detect peaks in the filtered waveform using `scipy.signal.find_peaks` and calculate the breaths per minute (`bpm`).
4. **State Decision**:
   - `EMPTY`: No person present (variance across all bins is below a certain threshold).
   - `OK`: Respiration (peaks) is stably detected.
   - `STILL`: A person is present, but breathing is temporarily too shallow or stopped.
   - `CHECK`: Sudden large movements (e.g., movement artifacts or falls) are detected.
   - `ALERT`: A person is present, but no breath (peaks) has been detected for 10 seconds or more.

### [Output Data Format (to stdout)]
1. **Per-frame Status JSON (20 times/sec)**:
   `{"t": 76.6, "state": "OK", "bpm": 16.2, "disp_mm": [0.81, 0.95, 1.02, 1.07], "motion": 120, "present": true, "chest_cm": 82}`
   *Include the 4 newest chest-movement points in `disp_mm`. Set `bpm` to `null` if unknown.
2. **Event JSON & Voice Alert on Anomaly**:
   When breathing stops for 10 seconds, output `{"type": "alert", "reason": "no_breath", "since_s": 10}`. Simultaneously, trigger a text-to-speech voice command saying "大丈夫ですか？" using a non-blocking background process (e.g., `subprocess.Popen`) so that the main data-processing loop never stops.

### [Execution Structure]
The script must read streams from `sys.stdin` line by line in real time to process the inputs continuously.
