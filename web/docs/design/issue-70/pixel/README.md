## 表示範囲とデータの境界

- LIVE の縦軸は最小±2mm。履歴内の最大絶対値が範囲の90%を超えると±4 / ±8 / …mmと2倍刻みで拡大し、通常波形と既存の欠測トレースの両方を含めます。大きな変位が既存30秒履歴から外れるまで範囲を保持します。
- `表示範囲 ±… mm · 自動拡大` と数値目盛で尺度を明示します。これは**描画の尺度**であり、呼吸・健康の閾値ではありません。開発用 DEMO の固定±2mmは従来通りです。
- サンプル値・時刻・単位・`dt_ms`・欠測・30秒窓・元の直線描画は同じです。平滑化・再補間・周期削減は行っていません。32回/分の30秒 fixture は約16周期を保ちます。
- 空配列・nullと0mmを区別します。過去に描いた波形や欠測の破線を消して構図だけを似せることはしていません。

## 残る差

- 参考の装飾曲線は周期が少なく、実データの32回/分と一致しません。約16周期と実際の振幅を優先しています。mobile のプロットは74px（参考換算約91px）ですが、出所・数値単位・凡例を残してカード全体をコンパクトにしています。
- 固定したブランドや既存の文字階層により、desktop のヘッダーやタイトルは参考を拡大したものと同じ比率ではありません。desktop はプロットの余白を増やすため通知開始が765→809pxへ下がります。mobile では約63px / ALERT約97px上げています。
- mobile の指標は参考より短く、直下に推定値の理由を別行で残します。通知の折り返し・継続中の警告・出所により、参考の短い例示履歴と行数は一致しません。
- `FileReplay`、推定値の説明、医療機器ではない注意書きを維持しています。姿勢・健康判定・未対応の設定や #75 の API は追加していません。
- 実機・macOS・Safari/iOS・スクリーンリーダーは未検証です。OS の日本語フォント描画も異なります。完全なアクセシビリティ監査や医療的検証ではありません。
